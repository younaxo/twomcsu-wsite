# NIGHT MODE

- NIGHT MODE сейчас НЕАКТИВЕН.
- Старые проценты использования и обещания из исторических файлов не являются текущими целями или гарантиями.
- Активация возможна только отдельной явной командой владельца с утверждённым scope, бюджетом, временем, stop conditions и разрешёнными действиями.
- Даже при активации остаются запреты на push/merge/deploy/migrations, секреты и новый scope без отдельного одобрения.
- Порядок подготовки описан в `docs/agent-prompts/NIGHT-MODE-OPERATING-PROCEDURE.md`.
