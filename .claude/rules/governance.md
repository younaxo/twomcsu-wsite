# Governance

- Владелец — единственный источник разрешения на новый scope, расходы, внешние действия и публикацию.
- Сначала исследование и план; запись только в явно назначенной области файлов.
- Не активировать Agent Teams. Использовать только вложенные project subagents.
- Координаторы не реализуют продуктовый код; специалисты не расширяют scope.
- При конфликте инструкций остановиться и запросить решение Owner Liaison.
- Не считать исторический CHECKPOINT текущим разрешением.
