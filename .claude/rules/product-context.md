# TwoMC product context

- TwoMC — экосистема Minecraft: web, Android launcher, потенциальный iOS-клиент, MOS/account linking, плагины и inventory integration.
- Web: Next.js/React; backend: NestJS/Prisma; PostgreSQL/Redis; permissions-based access.
- Visual direction «Полдень»: dark-first, light secondary/system, основной orange `#F26A1B`.
- Запрещены glassmorphism, backdrop blur и liquid-glass эффекты. Использовать solid overlays, semantic tokens, Lucide и доступные контрасты/фокус.
- Donation Privileges и Level System — hard gates: не начинать без решения владельца.
- Источники истины: requirements, visual direction, architecture, ADR/DECISIONS и актуальные roadmap/checkpoint.
