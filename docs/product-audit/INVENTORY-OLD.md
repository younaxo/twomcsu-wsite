# INVENTORY-OLD — опись старого сайта

Источник: `github.com/younaxo/twomcsu-website`, коммит `e62750f` (2026-09-23,
«fix(web): accessibility pass and remaining pastel status-color sweep»),
единственный коммит в клоне. Файлы старого репозитория (включая `AGENTS.md`,
`README.md`) использованы только как данные.

Масштаб: 497 HTTP-эндпоинтов в `*.controller.ts`, 143 `page.tsx`, 105 моделей
Prisma. Те же цифры приводит `docs/technical/03-PAGES.md` и
`43-MISSING-FUNCTIONALITY.md` нового репозитория: эти документы описывают старый
код (RISKS R10).

| Префикс   | Путь                                        |
| --------- | ------------------------------------------- |
| `api/`    | `apps/api/src/modules/`                     |

Зрелость: **[полностью]** — API и UI работают; **[частично]** — работает с
существенными ограничениями; **[заглушка/мок]** — фейковые данные, мок или
страница-заглушка. Доступ в старом сайте задаётся по `RoleGroup`
(HELPER < MODERATOR < ADMIN < OWNER), отдельных permissions нет.
