# INVENTORY-NEW — опись нового сайта

Состояние: `main` = `e5d86bf` (после PR #62). Незакоммиченная работа ветки
`feature/account-settings` (`/settings`, `/settings/privacy`,
`apps/web/src/lib/account/hooks.ts`, `packages/shared/src/api/account.ts`,
включение пункта «Настройки» в меню) в описи не считается готовой и помечена
«в работе».

Масштаб: 80 файлов `*.controller.ts` (83 класса контроллеров), 471
HTTP-эндпоинт, 3 WebSocket-namespace (`/chat`, `/messages`, `/notifications`),
118 моделей Prisma. Web вызывает около 25% эндпоинтов, из WebSocket — только
`/notifications` (`lib/notifications/hooks.ts:151`). Тесты: api unit 29, web
unit 178, e2e 33 сьюта / 242 теста (`STATUS.md`).

Сокращения путей:

| Префикс   | Путь                                     |
| --------- | ---------------------------------------- |
| `api/`    | `apps/api/src/modules/`                  |
| `web/`    | `apps/web/src/app/`                      |
| `cmp/`    | `apps/web/src/components/`               |
| `lib/`    | `apps/web/src/lib/`                      |
| `e2e/`    | `apps/api/test/*.e2e-spec.ts`            |
| `schema:` | `apps/api/prisma/schema.prisma:<строка>` |

**[частично]**, **[нет]**. Доступ — RBAC: `@RequirePermissions` и реестр
`packages/shared/src/permissions.ts` (ADR-0051), не `RoleGroup`.
