## Заблокировано внешне (нужен владелец)

- **Доставка писем** (R4): SMTP Beget, MX на Cloudflare — без него коды
  подтверждения почты в production не уходят.
- **Telegram OIDC** (R18): настройка бота в BotFather и Client Secret.
- **Minecraft-плагин** (R20): команды `/site-connect` на серверах; скриншоты
  для tutorial, ссылки на видео YouTube/RuTube, официальный SVG RuTube.
- **Production-ключи Turnstile** (R17) и **данные хостинга** для деплоя (R8).
- **Тексты юридических документов**: страницы `/legal/*` готовы, тексты —
  от владельца.
- **Брендированные страницы Cloudflare 502/503/504** (R21) — отложены по
  решению владельца.

## Известные ограничения

- Массовые рассылки (системные сообщения, уведомления объявлений) —
  синхронные O(n); при большой аудитории нужна очередь.
- WebSocket-шлюзы (чат, ЛС) не проверяются guard'ом модулей — закрыты их
  REST-методы.
- График онлайна игроков не строится: нет периодического сборщика статусов
  серверов.
- Сезонные баннеры — только флаг настройки, компонента баннеров нет.
- Компонент вывода emoji появится вместе с реакциями (волна Social).
