# Проверка адаптивности 375–1920 (2026-10-10)

Метод: dev-сборка (`next dev` + API на реальных данных dev-БД), вход локальным
QA-администратором. На каждой странице скрипт в браузере ищет горизонтальное
переполнение: `scrollWidth > clientWidth` документа и элементы, правый край
которых выходит за экран (кроме `position: fixed`, декоративных `aria-hidden`
и рядов вкладок, которые штатно прокручиваются в своём контейнере).

## Ширины

375 (телефон), 768 (планшет), 1920 (широкий экран); 1440 — основная ширина
разработки.

## Страницы

- Сайт: `/`, `/shop`, `/rules`, `/servers`, `/status`, `/legal/terms`.
- Вход: `/login`, `/register`, `/forgot-password`.
- Админка: дашборд, пользователи, роли, permissions, контент, финансы,
  сообщения, объявления, оформление, техработы и модули (обе вкладки),
  хранилище и журналы, настройки, безопасность, журнал аудита, экспорт,
  инструменты.

## Найдено и исправлено

| Где                        | Проблема                                                              | Исправление                                                                                                                      |
| -------------------------- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Админка → Роли (375)       | Пиксельный префикс роли шире карточки — страница шире экрана (409 px) | `RolePrefix`: `max-w-full` у обёрток; префикс ужимается в ширину контейнера (`object-contain`, `pixelated`), `shrink-0` сохранён |
| Админка → Объявления (375) | Таблица из 5 столбцов прокручивалась внутри карточки                  | «Статус» скрыт до `sm`, «Показ» и «Где и кому» — до `lg`; на узком экране статус, период и аудитория показаны под заголовком     |

Остальные страницы на всех ширинах — без переполнения. Ряды вкладок
(«Настройки») на 375 прокручиваются горизонтально в своём контейнере — это
поведение компонента `Tabs`.

## Не проверено

- Страницы, которых пока нет (профиль игрока, чат, ЛС) — будут проверены в
  волнах Product Completion.
- Реальные устройства (Safari iOS, Android Chrome) — только эмуляция ширины.
