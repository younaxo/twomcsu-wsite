# Приоритеты TwoMC: кратко (v1.0, 2026-11-17, черновик на согласование)
Полный план: docs/plan/PRIORITY-PLAN-DRAFT.md. Roadmap не менялся; расхождения только предложениями. Код по плану не пишется до «согласовано».
## Что показал код
- Магазин: бэкенд ~85 % (каталог, корзина, промокоды, заказы, вебхук с подписью), веб ~20 % (только каталог /shop), админка магазина в вебе ~5 % (есть лишь admin/finance).
- Платёж: только тестовый провайдер (dev/test), в production оформление отвечает 503; реального адаптера нет, возврат лишь меняет статус; выдачи купленного нет; кошелёк только чтение.
- Не опубликовано: около 20 локальных веток, 123 коммита над main (безопасность, /bans, Bridge, инвентарь).

## Слои
- Слой 0 (минимум): купить и оплатить + админка магазина + заказы и история в профиле + рабочая платёжка.
- Слой 1: /bans и «Мои наказания», остальная админка, профиль подробнее.
- Слой 2: Bridge, выдача игровых товаров, инвентарь, статистика, контент, кошелёк и рубины.
- Слой 3 (последним): чаты, мини-игры, азарт, розыгрыши. Закрыты gate: донат-привилегии 05–06, Level 11, мини-игры 12, вынос API 16.

## Подэтапы слоя 0
0.0 публикация безопасного фундамента в main (2FA и права, ADR-0183, обращения срез 2) — M
0.1 витрина: страница товара, фильтры, поиск — M
0.2 корзина и промокод — M
0.3 админка товаров, вариантов, категорий — L
0.4 админка заказов, промокодов, скидок — M
0.5 оформление и оплата в тестовом режиме, акцепт оферты — M
0.6 «Мои заказы» и история в профиле — S–M
0.7 выдача купленного (сайт сразу, игровые через очередь) — L
0.8 адаптер реального провайдера в песочнице — M–L
0.9 возврат на исходный способ и сверка платежей — M
0.10 production-минимум и приёмка (владелец выкладывает) — M + внешнее

## Критический путь до первой оплаты
Решения D1–D6 -> публикация фундамента -> слой 0 в песочнице -> (параллельно, внешний срок) юр. статус, провайдер, сервер -> 0.8–0.9 -> 0.10 -> боевые ключи (только владелец) -> приёмочная оплата. Узкое место: юридическое оформление, провайдер, сервер.

## Сроки (диапазоны, допущения в плане)
Слой 0 около 4–7 недель работы агентов при двух дорожках, без ожидания внешних шагов; слой 1 около 3–6 недель. Срок первой боевой оплаты определяется внешней цепочкой, не кодом.

## Решения владельца
D1 дата запуска и сроки. D2 платёжный провайдер (R2). D3 юр. статус (самозанятый, ИП, ООО) и чеки 54-ФЗ. D4 оферта, политика ПДн, возвраты. D5 что продаётся (рекомендация: рубли напрямую; без баланса, рубинов и привилегий 05–06). D6 что такое «минимум». D7 хостинг и production. D8 политика возвратов. D9 quick-buy и UNBAN/UNMUTE (рекомендация: не включать). D10 тестовые ключи песочницы. D11 согласие на изменения порядка. Плюс открытые Q36, Q39–Q41, Q44, Q46, Q56, Q58, Q66, Q69, значения ADR-0183.

## Расхождения с roadmap
Этапы 13–14 раньше 02–12; этап 13 требует привилегий (gate 05–06); Q67 прячет «Заказы» (противоречит 0.6); волна 4.4 предлагает отдельный канал выдачи вместо Bridge.
