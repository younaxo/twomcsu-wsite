# Решения владельца: экономика, розыгрыши и мини-игры

- Версия: 1.0
- Дата: 2026-11-16
- Источник: команда владельца в основном сеансе `twomc-chief` (текст сохранён без изменений смысла).
- Статус: обязательны для всех этапов. **Hard gate:** реализацию не начинать (Level System, Donation Privileges, мини-игры, конкурсы, платежи, передача рубинов), пока владелец не даст команду на соответствующий этап. Сейчас только документ.
- Юридические вопросы помечаются как «требует решения владельца»; агенты юридических заключений не дают.

## 1. Розыгрыши и конкурсы

1.1. Любой розыгрыш или конкурс с физическими или денежными призами: участие только бесплатное. Нельзя покупать билеты (ни за рубли, ни за баланс, ни за рубины). Привилегии не дают дополнительных билетов или множителей шанса. Билеты, если они есть, выдаются бесплатно (например, за активность) и не продаются, не передаются.

1.2. Предпочтительный формат для физических призов: конкурсы на навык (постройки, скриншоты, турниры, ивенты), где результат определяется результатом или жюри, а не жребием.

1.3. Розыгрыши на виртуальные призы: платные билеты и бонусы привилегий не вводить, пока владелец не подтвердит после консультации с юристом. По умолчанию бесплатное участие.

## 2. Мини-игры случая (рулетка, краш, апгрейдер и аналогичные)

2.1. Бонусы привилегий (x2, x3 и любые другие множители шанса или выигрыша) из этих игр полностью исключены. Привилегии на шансы в играх случая не влияют.

2.2. Рубины и монеты, полученные выигрышем в таких играх, НЕЛЬЗЯ передавать другим игрокам. Их можно только потратить. Нужно отслеживать «выигранную» часть баланса отдельно от остальной (ведомость по источникам), чтобы запрет передачи работал точно.

2.3. Вывод рубинов и монет в рубли запрещён. Рубины не деньги.

2.4. Публичные шансы и правила игр; игровая логика только на сервере (клиенту не доверять).

2.5. ОТКРЫТЫЙ ВОПРОС для владельца и юриста: разделить ли валюты на две (платные рубины для магазина и привилегий, бесплатная игровая валюта для игр случая). Рекомендация: разделить. Реализацию на этой основе не делать без команды.

## 3. Передача рубинов

3.1. Передача допускается только привилегиям, как в списке привилегий, с комиссией и без множителей при передаче.

3.2. Нужны суточные лимиты на перевод (значения задаёт владелец), журнал всех переводов, проверка подозрительных цепочек.

3.3. Правила проекта запрещают перепродажу рубинов за деньги; нарушители блокируются. Это защита проекта, но не заменяет юридическую проверку.

## 4. Баланс в рублях

4.1. Возврат только на тот же кошелёк или карту, с которых было пополнение, и только в размере непотраченного остатка. Это для будущего этапа платежей, сейчас не реализовывать.

## 5. Общее

5.1. Юридическую проверку схемы мини-игр, конкурсов и рубинов делает владелец с юристом до начала этапов 12 и 14. Агент не даёт юридических заключений: в отчётах такие места помечаются как «требует решения владельца».

5.2. Возрастные ограничения для платных механик случая: открытый вопрос для владельца.
