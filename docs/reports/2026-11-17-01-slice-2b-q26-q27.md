## 8. Исправления по ревью

- M1 (medium): `PATCH .../notes/:noteId/pin` под `reports.notes.pin` принимал `pinned:false`, и держатель pin без unpin открепил бы заметку в обход права unpin. Решение: единственный путь открепления — `DELETE .../notes/:noteId/pin` под `reports.notes.unpin`; PATCH только закрепляет, `pinned:false` даёт 400 с указанием на DELETE (поле `pinned` в DTO оставлено для обратной совместимости тела). Web должен перейти на `DELETE .../notes/:noteId/pin`. Тесты: unit (`reports-rbac.spec.ts`), e2e статически (`reports-support.e2e-spec.ts`: PATCH false -> 400; pin без unpin: DELETE -> 403; unpin без pin: DELETE -> 200, PATCH -> 403).
- L-1: R40 переписан по факту (смена статуса без миграции не падает, уведомление теряется с `logger.warn`); в чек-лист добавлены порядок выкладки, проверка логов, сверка PostgreSQL (`postgres:16-alpine`, требование 12+ выполнено).
