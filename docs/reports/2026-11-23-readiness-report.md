## 2. Методика и основания

### 2.1. Единицы и веса
Единица = подэтап плана (слой 0: 0.0–0.15; слой 1: 1.1–1.5; 1.6 «Розыгрыши» считается отдельно). Вес по колонке «Объём» плана: S = 1, S–M = 1,5, M = 2, M–L = 2,5, L = 3; 0.8 (платёжный слой) = 4 (0.8a = 1, 0.8b = 3); 0.10 = 2. Каждая единица делится на долю web и долю api (api включает БД, интеграции, ops/runbook).
Статус единицы по факту: «слито» (PR в main) = 1,0 веса; «слито частично» = доля по фактически слитому; «в ветке» не даёт кредита в колонке «слито», но в колонке «в ветках»; «не начато» и «заблокировано» = 0. Hard gates (0.8b, боевые ключи, production-деплой, Donation/Level, мини-игры, передача рубинов) выполненными не считаются.

## 7. Риски и оговорки

1. Возможный дефект cookie two_factor_challenge (подтверждён статическим анализом, в браузере не воспроизводился). apps/api/src/modules/auth/refresh-cookie.ts:44 задаёт Path=/auth (функция twoFactorCookieOptions). В apps/api/src/main.ts глобального префикса нет, то есть маршруты API — /auth/...; на стенде nginx (infrastructure/test-website/nginx.stand.conf.template, location /api/ с proxy_pass на «/») отрезает /api, но браузер видит путь /api/auth/... и по правилам Path не отправит cookie с Path=/auth на запросы /api/auth/... Итог: второй шаг входа с 2FA (login с кодом) может отвечать «время истекло»; это затрагивает персонал, у которого 2FA обязательна (Q22), и вход через соцсети (social-auth.controller.ts использует тот же cookie). Cookie refresh_token не затронут (Path=/). Если в production API будет на отдельном домене с путём /auth — дефект не проявится. Рекомендация: отдельный срез — путь cookie из конфигурации; проверить в браузере. Зафиксировано как Q105 (допущение).
2. Проценты — оценка по весам, не измерение; шаг 5 %. Тесты, сборка, e2e в этом прогоне не запускались; статус CI и покрытие не проверялись.

4. Все финансовые флаги выключены по умолчанию — «слито» не означает «включено и проверено в production».
5. 0.12 «платное снятие наказаний» — только заготовка; зависит от 0.13 и решения Q79.
