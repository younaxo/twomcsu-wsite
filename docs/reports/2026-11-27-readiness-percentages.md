## Как считались проценты

- Для каждой строки взяты критерии приёмки из `docs/plan/PRIORITY-PLAN-DRAFT.md` (v1.1) или список «что нужно для боевого запуска» из `docs/runbooks/go-live-plan.md` и `acceptance-checklist.md`.
- % = выполненные критерии / все, округление **вниз** до 5.
- «Выполнено» = код в `main` + есть тест. Код за выключенным флагом без живой проверки (реальный провайдер, игровой сервер) учитывается с половинным весом.
- Где исследователь давал больше, а есть открытый риск HIGH, выключенный флаг или нет живой проверки, Chief поставил меньшее число; причина — в строке.
