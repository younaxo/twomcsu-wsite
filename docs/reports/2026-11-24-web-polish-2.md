## Допущения и риски

- Допущение: 403 на странице приглашения объединяет «истекло», «использовано» и «выдано другому»; различать их по статичному тексту нельзя.
- Тосты (`getErrorMessage` в ~200 местах) не менялись: вне ErrorState.
- Заголовки ErrorState с явным `title` на главной переопределяют заголовок 503/техработ; различие передаёт описание.
- `cartErrorMessage` (lib/store/cart.ts) для 4xx без известного кода по-прежнему показывает `messages[0]`: существующие тесты корзины требуют этого. Нужно решение: перевести на коды API. Сырой текст убран только из блока `cart-promo-problem`; он остаётся в fieldError/rowError/error/clearError корзины (cart/page.tsx ~100-220, 369, 695) и в `FormErrorSummary` оформления (checkout/page.tsx:362, lib/store/checkout.ts:322). Утверждать «без сырых сообщений» для корзины и оформления нельзя.
- Пункт «Скоро» в sidebar-rail без `opacity-60` визуально похож на активный и подсвечивается по hover (`itemClassName` содержит `hover:bg-muted`). Проверить глазами на стенде; при необходимости пунктир или замок, либо отключить hover для `[data-soon]`.
- SoonItem: focusable `span` с `aria-disabled` без `role`. Проверить в NVDA; альтернатива — `role=link`.
- Тот же паттерн утечки остался вне scope: `messages/invite/[code]/page.tsx:27` — `description={getErrorMessage(invite.error)}`.
- Ревью twomc-reviewer: approve with comments, блокеров нет. tsc, vitest и eslint ревьюер не перезапускал.
