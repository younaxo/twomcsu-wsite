## 7. Риски и расхождения

- Дизайн раздела 6 показывал silent по умолчанию; контракт скрывает (Q57/О1) - расхождение записано как Д1.
- `users.punishments` шире по охвату, чем просмотр зеркала; отдельное `punishments.view` - Q63.
- `ref` раскрывает число непубличных записей (без содержимого).
- `publicRef` среза 1 не проверяет длину `sourceId`: для 19-значного id получился бы `ref`, не проходящий регэксп контракта (до 18 цифр); для автоинкрементных id LiteBans недостижимо; проверку добавляет срез реализации.
- Скрытая запись видна клиентам до 5 + 15 + 30 с (порядка 50 с); серверный кэш обязан сбрасываться при `isHidden`.
- Очистка текстов эвристическая (R56): игрок может увидеть остатки чужих данных в своих записях.
- Расхождение копий типов api и shared - R80.
- Индекс и частичный индекс: план `EXPLAIN` с параметризованным `LIKE` может не использовать индекс (запасной вариант описан в контракте).
- ADR-0179 в `DECISIONS.md` отсутствует (после ADR-0178 идёт ADR-0180); ссылки на него в документах нет.
