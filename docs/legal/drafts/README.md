# Пакет документов для модерации сайта у платёжного провайдера (индекс)

> ЧЕРНОВИК, заменяет владелец; не является юридической консультацией.

Назначение: черновики общих документов, которые обычно запрашивают при модерации сайта и магазина у платёжного провайдера. Пакет подготовлен для владельца. Провайдер не выбран (D2), статус продавца не определён (D3). Ничего не опубликовано, web-срез страниц не сделан, в анкету провайдера ничего не подано.

Дата подготовки: 2026-11-24. Сводка для chief: `docs/reports/2026-11-24-provider-moderation-pack.md`.

## Как пользоваться

1. Прочитать 08 (чек-лист) и 09 (вопросы юристу). Передать 09 юристу и бухгалтеру.
2. Решить вопросы из раздела «Решения владельца» каждого документа. Маркеры `[РЕШЕНИЕ ВЛАДЕЛЬЦА: ...]` указывают, что решает владелец.
3. Заменить плейсхолдеры реальными данными после подтверждения владельца (см. список ниже).
4. Тексты 01–05 заменить итоговыми версиями после проверки юристом. Плашку «ЧЕРНОВИК» убрать.
5. Текст 06 и 07 уточнить по фактическому состоянию выдачи и по опубликованным правилам.
6. Публикацию страниц (web-срез) и адрес боевого домена делает chief и владелец. Агент их не делает.
7. Анкету провайдера заполняет и подаёт владелец.

## Плейсхолдеры

Допустимые в пакете: `[РЕКВИЗИТЫ]`, `[ИНН]`, `[ОГРН/ОГРНИП]`, `[АДРЕС]`, `[EMAIL]`, `[ТЕЛЕФОН]`, `[ДАТА]`, `[НАИМЕНОВАНИЕ ПРОДАВЦА]`, `[СРОК]`, `[ДОМЕН]`, `[СТАТУС ПРОДАВЦА]`.

В пакет не вписаны: реквизиты, ИНН, имена, телефоны, адреса, URL провайдера и название выбранного провайдера. Значения по умолчанию из конфигурации сайта не использованы и не подтверждены владельцем.

## Правило пакета

Ничего не удалять. Документы этого пакета дополняются новыми файлами или новыми версиями рядом со старыми. Замена текста делается после решения владельца и проверки юристом. История правок сохраняется в сводке для chief.

## Известные расхождения между документами (проверить до публикации)

- 01, п. 5.1 описывает выдачу командой на сервер как факт. 06 фиксирует, что по умолчанию выдача ручная, а автоматическая выдача выключена до решения владельца. Формулировку 01 согласовать с 06.
- 03 содержит демо-цены (варианты «3 месяца» и «навсегда» рассчитаны коэффициентами). Цены подтверждает владелец.
- 07 не содержит текста правил: он хранится в базе на странице `/rules`.
- Подробный список расхождений: `docs/reports/2026-11-24-provider-moderation-pack.md`, раздел 4.
