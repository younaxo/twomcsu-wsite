# Регистрация боевого сервера Bridge (только владелец)

Назначение: подключить 4–6 боевых Minecraft-серверов (Q42) к приёмнику `/bridge/v1`.

## Правила

- Боевую регистрацию выполняет ТОЛЬКО владелец. Агент скрипт регистрации в production никогда не запускает.
- Скрипт `apps/api/scripts/bridge-register-server.ts` для боевой БД требует оба флага: `--production --confirm-owner`. Без них скрипт отказывается работать с не-локальной БД.
- Ключ сервера выводится только владельцу в терминал, в чат, репозиторий, логи и отчёты он не попадает. Ключ передаётся на сервер напрямую в конфигурацию плагина.
- Мастер-секрет (`BRIDGE_MASTER_SECRET`) задаёт владелец в production `.env`, не менее 32 байт и высокой энтропии (слабое значение приёмник отклонит при старте; значение в сообщении об ошибке не печатается).

## Порядок

1. Убедиться, что в production заданы `BRIDGE_ENABLED=true` и `BRIDGE_MASTER_SECRET`.
2. Для каждого сервера выполнить регистрацию с уникальным `slug`, указав `--production --confirm-owner`; сохранить выведенный ключ в конфиг плагина этого сервера.
3. Проверить `bridge.hello` от плагина: `pluginVersion` и `platform` в допустимом формате.
4. Указать `sourceScope` сервера; опрос LiteBans не отключается (R132), авторитетный источник решает владелец.
5. Ротация и отзыв ключа - по разделу 2.4 контракта `docs/stage-03/BRIDGE-CONTRACT.md`; печать ключа - `apps/api/scripts/bridge-print-key.ts`, также только владелец.
