# Промпт 21 — 0.8b: маршрутизатор способов оплаты (23.11.2026)

Источник: сообщение владельца в чате 23.11.2026 вечером. Пересказ.

- 0.8b — не привязка к одному провайдеру, а маршрутизатор способов оплаты: на оформлении игрок выбирает способ (СБП, карта РФ, SberPay; позже иностранная карта, крипта), маршрутизатор направляет платёж нужному провайдеру через общий интерфейс PaymentProvider.
- Реализация на моках: мок-провайдер РФ, мок-крипто, мок-иностранные карты; общая подпись вебхуков, идемпотентность, возвраты и сверка.
- Конкретные адаптеры (ЮKassa, Robokassa, крипто, агрегатор) — только после того, как владелец назовёт провайдера и даст тестовые ключи.
- В список документов для провайдера включить готовый пакет для модерации сайта: оферта, политика возвратов, описание товаров, контакты (черновики; владелец заменит).
- Вопросов не задавать.
