Тривиальное не делегировать; лимит расходовать на критический путь.
- Пороги ОЗУ/диска не запрет, но тяжёлое (сборка web, полные e2e, Docker, бенчмарки) — на VDS через один «раннер» (скрипт и очередь); локально только код, git и лёгкие тесты; при локальном тяжёлом — следить, чтобы ПК не выключился. К VDS — одним сеансом, через очередь (fail2ban).
- Эксперимент Rust/Java — низкий приоритет, только на VDS.
