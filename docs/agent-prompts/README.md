# TwoMC agent prompt library

Эта папка хранит master prompts и шаблоны передачи задач между Claude Code agents.

## Запуск из корня репозитория

1. Запустить `claude --agent twomc-chief`.
2. В интерактивном сеансе написать: `Прочитай @docs/agent-prompts/<имя-файла>.md и выполни задачу строго в указанном scope.`
3. Для каждой передачи заполнить `HANDOFF-TEMPLATE.md` и сохранить артефакт задачи в отдельном Markdown-файле этой папки или в согласованной task-папке.
4. После выполнения добавить фактический результат и проверки; не переписывать исходный scope задним числом.

Master prompt — versioned Markdown, а не текст, существующий только в чате. Любое изменение scope, бюджета, внешних действий или критериев завершения требует новой версии и решения владельца.

## Файлы

- `MASTER-PROMPT-TEMPLATE.md` — шаблон крупной задачи.
- `HANDOFF-TEMPLATE.md` — контракт между уровнями иерархии.
- `AI-ADVISOR-BRIDGE.md` — безопасный мост к внешнему AI Advisor через OpenAI API.
- `NIGHT-MODE-OPERATING-PROCEDURE.md` — документированный, но неактивный процесс.
- `DRY-RUN-PROMPT.md` — read-only проверка цепочки делегирования.
- `DRY-RUN-REPORT.md` — фактический результат последней проверки иерархии.
