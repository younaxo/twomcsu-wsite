# Промпт 18 — VDS и тестовый стенд основного сайта (23.11.2026)

Источник: сообщения владельца в чате 23.11.2026 (днём). Пересказ без секретов.

## 18.1. Настройка VDS
- VDS 31.76.77.45, вход root по ключу twomc_giveaway_vds (пароль root не передаётся).
- Отдельный пользователь с sudo и тем же ключом; вход по паролю и root по SSH выключить; firewall (SSH, 80, 443); fail2ban; синхронизация времени.
- Docker, nginx, certbot. Секреты генерировать на сервере и не печатать. Миграции разрешены на базах этого VDS.
- После настройки напомнить владельцу сделать снимок диска в панели хостинга.

## 18.2. Домены
- test-website.twomc.su — тестовый стенд ОСНОВНОГО сайта (вместо dev.twomc.su).
- giveaway.twomc.su — розыгрыш, на паузе, не выкладывать.
- Позже основной сайт будет на twomc.su: домен из конфигурации (PUBLIC_URL, nginx, CORS, cookie без жёсткой привязки), перенос = смена настроек и сертификата.

## 18.3. Выкладка для тестирования владельцем
- Актуальный main (слои 0 и 1); API, web, БД, Redis; миграции на базе стенда; демо-данные (14 товаров с ценами twomc.su, новости, правила, формы, рейтинги и т. д.).
- Тестовый провайдер платежей; флаги видимых модулей (/bans, магазин, профиль, админка).
- HTTPS (certbot), basic auth и noindex (robots + X-Robots-Tag).
- Логин и пароль basic auth: генерировать на сервере, файл с правами 600, владельцу только путь.
- Тестовые учётные записи (игрок, администратор): данные в файле на сервере (600), владельцу только путь.
- Смоук: главная, /shop, корзина, оформление с тестовой оплатой, «Мои заказы», /bans, профиль, админка (товары, заказы, наборы, промокоды). Владельцу: адрес, что работает и что нет.
- Если что-то не запускается — выложить работающее, остальное в отчёт.
- Повторяемая выкладка одной командой (в стиле giveaway), описание в docs/runbooks/.
- Работать автономно, вопросов не задавать.
