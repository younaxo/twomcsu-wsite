# Картинки призов

Сюда кладутся PNG-файлы призов (ADR-G003 п. 5.5). Загрузки через сайт нет:
файлы добавляет организатор вручную (на сервере - в каталог из
`GIVEAWAY_PRIZES_DIR`, по умолчанию `giveaway/prizes`).

Правила имени: `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}\.png$` - латиница, цифры,
точка, дефис, подчёркивание, расширение `.png` в нижнем регистре, не длиннее
64 символов до расширения. Подкаталоги не поддерживаются.

В админке выбор приза идёт только из списка найденных здесь файлов
(`GET /admin/prize-images`); имя файла никогда не используется как путь.
Публичная страница берёт картинку как статический файл
`/giveaway/prizes/<имя>` (путь настраивается nginx).

Рекомендация: квадратный PNG 512x512, до 300 КБ.
