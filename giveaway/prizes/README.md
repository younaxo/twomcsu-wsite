# Картинки призов

Сюда владелец кладёт PNG-файлы призов (клавиатура, микрофон и др.). Загрузки через сайт нет: админка только выбирает файл из этого каталога по имени.

Правила:

- формат PNG, размер не более 2 МБ на файл;
- имя файла: латиница, цифры, `.`, `_`, `-`, начинается с буквы или цифры, не длиннее 64 символов, расширение `.png` (например, `keyboard.png`);
- файлы публикуются как статика на странице розыгрыша (`/giveaway/prizes/<имя>`); путь каталога для API задаёт `GIVEAWAY_PRIZES_DIR` (по умолчанию `../../giveaway/prizes` от `apps/api`);
- имя файла хранится в призе; переименование или удаление файла после выбора ломает картинку приза.

Контракт: `giveaway/docs/ADR-G003-admin-draw-live.md`, п. 5.5.
