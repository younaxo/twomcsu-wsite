# Панель прогресса розыгрыша: подключение плейсхолдеров

Плагин `TwoMCGiveaway` отдаёт данные через PlaceholderAPI (PAPI). Какой плагин панелей/HUD стоит на сервере, из репозитория неизвестно, поэтому здесь общая инструкция. Конкретный плагин выбирает владелец; ничего из названного ниже не является утверждённым решением.

## 1. Плейсхолдеры

Расширение `twomcgiveaway` регистрируется автоматически, если установлен PlaceholderAPI (иначе плагин работает без него). Значения берутся из кэша, обновляемого раз в минуту (`POST /progress`); сеть при чтении не используется.

| Плейсхолдер | Значение | Пример |
|---|---|---|
| `%twomcgiveaway_hours%` | целые часы набранного времени | `12` |
| `%twomcgiveaway_minutes%` | остаток минут (0-59) | `5` |
| `%twomcgiveaway_remaining%` | сколько осталось до порога, `ч:мм` | `37:55` |
| `%twomcgiveaway_percent%` | процент (целое, максимум 100) | `24` |
| `%twomcgiveaway_qualified%` | порог набран: `да` или `нет` | `нет` |
| `%twomcgiveaway_ticket%` | билет или `-` | `K417` |
| `%twomcgiveaway_threshold_hours%` | порог в часах | `50` |
| `%twomcgiveaway_start%` | старт (текст сайта, МСК) | `22.11 00:00 по МСК` |
| `%twomcgiveaway_cutoff%` | крайний срок (текст сайта, МСК) | `30.12 23:59 по МСК` |

Даты (`start`, `cutoff`) и порог (`threshold_hours`) берутся ТОЛЬКО из ответа сайта (`POST /progress`), в config.yml их нет. До первого ответа сайта они показывают `—`. Если игрока нет в кэше: `0`, `нет`, `-`, `remaining` равен порогу (или `—`, если порог ещё неизвестен).

## 2. Шаблон блока (текст)

```
Розыгрыш: Анархия Новой Эры
Онлайн: %twomcgiveaway_hours% ч %twomcgiveaway_minutes% мин из %twomcgiveaway_threshold_hours% ч (%twomcgiveaway_percent%%)
Осталось: %twomcgiveaway_remaining%
Билет: %twomcgiveaway_ticket%
До: %twomcgiveaway_cutoff%
```

Знак процента после числа экранируется по правилам конкретного плагина (в части плагинов `%%`).

## 3. Вариант с ресурс-паком: шрифтовые глифы и negative space

Идея: фон и рамку панели рисует картинка, подключённая как символ собственного шрифта ресурс-пака; текст с плейсхолдерами выводит HUD-плагин поверх неё. Требуется плагин панелей/HUD, умеющий PAPI и кастомные шрифты (Adventure `font`), и ресурс-пак, который клиент принимает.

Ресурс-пак принадлежит владельцу (pack.twomc.su, Q93); название плагина панели не определено. Пак не скачивался, ассеты не рисовались: ниже общая схема.

1. Ассет: `assets/twomc/textures/font/giveaway_panel.png`, PNG с альфой, ширина 192 px, высота 64 px (кратно 8, чтобы масштаб не размывался); тёмный фон (solid, без стекла и blur), акцент orange `#F26A1B`. Файл не включён в репозиторий (нарисовать должен дизайнер), положить сюда: `giveaway/plugin/panel/assets/`.
2. Шрифт: `assets/twomc/font/giveaway.json`:
   ```json
   {"providers":[
     {"type":"bitmap","file":"twomc:font/giveaway_panel.png","ascent":-4,"height":64,"chars":[""]},
     {"type":"space","advances":{"":-193,"":-1,"":-8,"":8}}
   ]}
   ```
   Глиф панели: `U+E000` (приватная область Unicode, в JSON ``). Negative space: `U+E001` сдвигает курсор на -193 px (ширина панели + 1), чтобы текст лёг поверх только что нарисованной картинки; `U+E002..U+E004` мелкие шаги (-1, -8, +8) для подгонки. Кодировка файлов: UTF-8 без BOM.
3. Вывод: строка HUD `<font:twomc:giveaway></font>` (картинка, затем возврат курсора), следом обычным шрифтом текст из шаблона п. 2. Точный синтаксис задаётся плагином панелей (MiniMessage, `&`-коды или свой формат); следуйте его документации.
4. Положение (над хотбаром, в углу) подбирается вертикальным смещением (`ascent`) и настройками плагина панелей. Проверьте при GUI scale 2, 3 и 4 и при разных разрешениях.
5. Игроки без ресурс-пака увидят квадраты вместо глифа: либо принудительный пак (`require-resource-pack`), либо запасной вариант из п. 4.

## 4. Запасной вариант через TAB (без ресурс-пака)

Использовать header/footer списка игроков или layout плагина TAB (либо аналога). Не использовать босс-бар и скорборд: они заняты другими механиками.

Готовый пример: [`tab-example.yml`](tab-example.yml) (header/footer и вариант layout). Пример footer (формат TAB, `\n` как разделитель строк; перенос строки зависит от версии плагина):
```
footer:
  - ""
  - "&6Розыгрыш: &f%twomcgiveaway_hours% ч %twomcgiveaway_minutes% мин из %twomcgiveaway_threshold_hours% ч &7(%twomcgiveaway_percent%%)"
  - "&7Осталось: &f%twomcgiveaway_remaining% &7| Билет: &6%twomcgiveaway_ticket%"
```
Плейсхолдеры PAPI в TAB подключаются как есть. Если плагин кэширует значения, задайте интервал обновления 5-10 секунд (данные обновляются раз в минуту).

## 5. Проверка

1. `/papi list` содержит `twomcgiveaway`; `/papi parse me %twomcgiveaway_remaining%` возвращает значение.
2. `/giveawaytime` показывает строку «Опрос прогресса» с успешными опросами.
3. Если значения пустые, проверьте: установлен ли PAPI до запуска плагина (softdepend), настроен ли ключ (`/giveawaytime`), `progress.enabled: true`.
